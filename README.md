## Research experience

### 3D reconstruction under degraded observations

- Participated in designing experiments comparing clean, snow-corrupted, and preprocessed observations for 3D Gaussian Splatting.
- Performed 2D refinement/preprocessing and compared reconstruction-related metrics before and after preprocessing.
- Focus: understanding how observation quality affects downstream 3D reconstruction.

[LongSplat baseline fork](https://github.com/KIMKYUDO/LongSplat) · [Original implementation by NVIDIA researchers](https://github.com/NVlabs/LongSplat)

The linked repository is an upstream research-code fork, not an original method authored by me or a release of all of my experiments.

### Open-vocabulary 3D perception

- Ran inference with the existing **OVIR-3D** model using ScanRefer data.
- Gained experience working with an existing open-vocabulary 3D inference pipeline.

This was supporting experimental work, not an original implementation of OVIR-3D. The related report is not currently released in these public repositories.
